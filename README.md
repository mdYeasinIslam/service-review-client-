# Adventa - Tourism Service Platform

A modern tourism service web application built with React and Vite, offering comprehensive travel solutions for Bangladesh.

## 📋 Project Overview

Adventa is a full-featured tourism platform that connects entrepreneurs with travelers, enabling browsing, reviewing, and managing tourism services.

## 🚀 Key Features

### Pages & Navigation
- **Public Pages**: Home, Services, Blog, Sign-In, Sign-Up
- **Private Pages**: My Reviews, Add Service, Profile (authentication required)

### Core Functionality
- **Home**: Banner, featured services, custom tourism sections, and footer
- **Services**: Browse all available tourism services with detailed information
- **Service Details**: View complete service information and user reviews
- **Reviews**: Users can add, view, edit, and delete their reviews
- **Service Management**: Admins can add new services (displayed on home page)
- **Blog**: FAQ section with tourism-related questions and answers

## 🛠️ Tech Stack

**Frontend Framework**: React 18.2.0 + Vite  
**Styling**: Tailwind CSS + Custom CSS  
**Authentication**: Firebase (Email/Password & Google OAuth)  
**HTTP Client**: Axios 1.6.2  
**Routing**: React Router DOM 6.16.0  
**UI Libraries**: React Icons, Framer Motion, React Photo View  
**Notifications**: React Toastify 9.1.3
